# 📊 Análisis de Ventas de Tiendas

## 📌 Introducción

Este proyecto tiene como objetivo analizar los datos de ventas de cuatro tiendas diferentes para identificar patrones de comportamiento, desempeño comercial y satisfacción del cliente.

A partir del análisis de los datos, se busca obtener información relevante que permita comprender el rendimiento de cada tienda y apoyar la toma de decisiones estratégicas.

---

# 📂 Dataset

Los datos provienen de cuatro archivos CSV, cada uno correspondiente a una tienda diferente.

Cada conjunto de datos contiene información sobre:

- Producto vendido
- Categoría del producto
- Precio de venta
- Costo de envío
- Fecha de compra
- Evaluación del cliente
- Tipo de pago
- Número de cuotas
- Ubicación geográfica de la compra

Los datasets se cargaron utilizando la biblioteca **Pandas** en Python.

---

# 🛠️ Herramientas utilizadas

- Python
- Pandas
- Google Colab

---

# 🔎 Análisis realizados

Se realizaron cinco análisis principales para evaluar el desempeño de las tiendas.

---

## 1️⃣ Análisis de facturación

Se calculó el ingreso total de cada tienda sumando los valores de la columna **Precio**.

Este análisis permite identificar qué tienda genera mayor volumen de ventas.

---

## 2️⃣ Ventas por categoría

Se analizó la cantidad de productos vendidos por categoría en cada tienda.

Esto permitió identificar cuáles son las categorías más populares entre los clientes.

---

## 3️⃣ Calificación promedio de la tienda

Se calculó la calificación promedio otorgada por los clientes para cada tienda.

Este indicador permite evaluar el nivel de satisfacción del cliente con los productos y el servicio.

---

## 4️⃣ Productos más y menos vendidos

Se identificaron los productos con mayor y menor número de ventas en cada tienda.

Este análisis ayuda a entender qué productos tienen mayor aceptación y cuáles presentan menor demanda.

---

## 5️⃣ Costo de envío promedio

Se calculó el costo promedio de envío para cada tienda.

Dado que el cliente asume este costo, es importante analizar cómo puede influir en la decisión de compra.

---

# 📈 Conclusiones

A partir del análisis realizado se pueden identificar diferencias en el desempeño de cada tienda en términos de ventas, satisfacción del cliente y costos asociados.

Estos resultados permiten comprender mejor el comportamiento del mercado y pueden servir como base para tomar decisiones estratégicas orientadas a mejorar el rendimiento de las tiendas.
